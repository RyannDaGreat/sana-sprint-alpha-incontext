FIBO2 training previews

Bria FIBO2 (Fibo 2.0 dev, 8.1B) trained the same way as our SANA trimask model: an adapter LoRA first, then a control LoRA that reads the trimask (white = object, gray = unknown, black = background) through FIBO2's native context input. Previews are written by the trainer every 500 steps: 4 fixed train items, fixed noise, 20 sampler steps, CFG 5, 1024² shown at ¼ size. They are training-time samples (adapter + control on, λ = 1), not the held-out evals.

Control run fibo2_tri: columns = trimask | FIBO2 output | reference on 50% gray

7 GPUs, 28 images per step, all 4 resolutions and all 19 trimask methods. The run crashed at step 2100 (a storage blip, 2026-11-19 1:37 AM ET) and resumes from step 2000.

Adapter run fibo2_adapter: columns = FIBO2 output | reference (random solid color background)

1000 steps, 8 GPUs, 32 images per step. Honest reading: by step 1000 the adapter only partly moved toward flat backdrops; most outputs are still scenes. The control run above learned the gray background anyway.

Published images are full-resolution WebP q95, hosted on the repo's journal-assets branch; originals are PNG in the repo's BlueJay database.
