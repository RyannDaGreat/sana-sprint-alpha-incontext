## 2026-11-17 10:10 — Step 2 adapter trainer (subagent 3)
- Teacher objective, verified from NVlabs/Sana sources (not papers): `SanaSprint_1600M_img1024_bf16_normT_allqknorm_teacher_ft.yaml` = predict_v, linear_flow, flow_shift 3.0, logit_normal(0, 1), timestep_norm_scale_factor 1000, class_dropout 0.1, gradient_clip 0.1, CHI prompt in training. `respace.py`: sigma = 3u/(1+2u) with u = sigmoid(N(0,1)); `gaussian_diffusion.py`: x_t = (1−σ)x0 + σε, target ε − x0. diffusers' transformer takes timestep = σ in [0,1] directly (the pipeline's 0.001 timestep_scale does the normT). So the teacher trains as plain rectified flow; TrigFlow is only the distillation wrapper. Implemented in `src/sana_alpha/train_objective.py`.
- Decision: full fine-tune, fp32 master weights, AdamW wd 0, bf16 autocast, fp32 safetensors checkpoints (diffusers format). Full FT is the "max rank" limit and fits (weights+grads+Adam = 24.3 GB). Nothing to bake; `W_base − W_adapter + W_control` stays exact in fp32.
- Pitfall (cost ~30 min): `SanaPipeline.encode_prompt(..., do_classifier_free_guidance=True)` left ~32 GB allocated on the GPU (diffusers 0.43; `do_classifier_free_guidance=False` does not). - Fact: caption embeddings trimmed to unmasked tokens (BOS + prompt, mean 15.5 tokens, 70 KB/caption; null "" = 1 token) give the same samples as the 300-padded ones (verified visually, same noise). MAGICK has 75,633 unique subjects for 140,955 images. Gemma with CHI pads to ~450 tokens, ~2.3 TFLOP per caption, only ~20 captions/s on a shared GPU: encoding each rank's shard once at startup is cheaper than online encoding (which would add ~18% compute every step).

## 2026-11-17 10:10 — GateControl port + control training code (control subagent)
- Files: `src/sana_alpha/gatecontrol.py` (port), `src/sana_alpha/train_control.py` (Step 3 trainer, preview, `merge_final`). Reuses `train_objective`, `train_text`, `train_data.rank_shard/epoch_batches`, `train_adapter.setup_distributed`, `models.localize`.

Gates live in `transformer.gatecontrol_gates`; the LoRA is PEFT adapter "control" on GateControl's official targets (rank 16, alpha 16 → 18.95 M trainable params incl. 0.09 M gates). `enable_gatecontrol` swaps the instance forward so a stock `SanaPipeline` drives the model: `pipe(..., attention_kwargs={"gatecontrol_cond": cond_latents})` (cond repeated over the CFG halves, as GateControl does). Without that key the forward is the base forward.
- Sprint-teacher differences handled: QK RMSNorm is per token (works on the concatenated sequence unchanged); the transformer takes timestep = sigma in [0,1] (timestep_scale 0.001 lives in the pipeline), not GateControl's 0..1000; no guidance embedding.
