Alpha and decontaminated color by iterative least squares

2026-11-20 · splitter model (manifest §17) · user request m00826 · code: fibo2.rgba_from_composites, web/src/splitter.js rgbaFromComposites

Result. The splitter model paints one object on K known backgrounds. Recovering transparency α and the object's true color F from those K images is a small constrained least-squares problem per pixel. The old one-shot linear fit followed by clipping is not its optimum: on our real step-500 splitter outputs it is worse on of pixels. Iterative least squares (alternating exact solves for F and α) reaches the same optimum as projected gradient descent and multi-start L-BFGS-B to ≤ 1e-13 in 16 iterations, for 2, 3 and 9 background colors, and recovers exact composites to float32 precision.

The problem

Input: K images of the same object, each composited on a known solid background color $b_k \in [0,1]^3$ (here gray 0.5, white, black; the method takes any K ≥ 2 distinct colors). Output: per pixel, opacity $\alpha \in [0,1]$ and straight (not premultiplied) foreground color $F \in [0,1]^3$, plus an uncertainty map. Domain: solid, exactly known backgrounds; the K images must show the same object (the splitter's heads are trained to).

Each image follows the compositing equation, so per pixel we solve

$$\min_{\alpha\in[0,1],\;F\in[0,1]^3}\;\sum_{k=1}^{K}\sum_{c\in\{r,g,b\}}\bigl(C_{kc}-\alpha F_c-(1-\alpha)\,b_{kc}\bigr)^2$$

Color decontamination comes for free: the backgrounds are known, so their share $(1-\alpha)b_k$ is removed exactly, and $F$ holds no gray, white or black spill. The uncertainty is the RMS residual of the fit: 0 when the K images agree with a single RGBA.

The old one-shot fit and why it is not enough

Substituting $u = 1-\alpha$ and $P = \alpha F$ makes the residual linear, $C_{kc} - P_c - u\,b_{kc}$, so the unconstrained optimum has a closed form:

$$1-\alpha=\frac{\sum_{k,c}(C_{kc}-\bar C_c)(b_{kc}-\bar b_c)}{\sum_{k,c}(b_{kc}-\bar b_c)^2},\qquad P_c=\bar C_c-(1-\alpha)\,\bar b_c$$

The previous code clipped α to [0, 1] and then $F = P/\alpha$ to [0, 1]. When either clip activates (opaque or fully clear pixels, saturated colors, noisy heads), the clipped point is feasible but not the constrained optimum, because α and F were not re-solved against each other.

Iterative least squares

Starting from the clipped one-shot fit, alternate two blocks. Each block is a 1-D convex quadratic per channel, so its box-constrained optimum is the unconstrained solution clipped:

$$F_c \leftarrow \operatorname{clip}\!\Bigl(\frac{\bar C_c-(1-\alpha)\,\bar b_c}{\max(\alpha,\varepsilon)},0,1\Bigr)\qquad \alpha \leftarrow \operatorname{clip}\!\Bigl(\frac{\sum_{k,c}(C_{kc}-b_{kc})(F_c-b_{kc})}{\sum_{k,c}(F_c-b_{kc})^2},0,1\Bigr)$$

Both updates need only per-pixel sums that are computed once ($\bar C$, $\sum_k(C_k-b_k)$, $\sum_{k,c}(C_{kc}-b_{kc})b_{kc}$), so one iteration costs a few operations per pixel and channel. The floor $\varepsilon = 10^{-9}$ is used only inside the F step: at α = 0 the objective ignores F, but F's direction lets α leave 0 on the next step. Without it, a pixel that starts at α = 0 can stall there; the first validation run found one such pixel (objective 1.2e-4 above L-BFGS-B). F is reported as 0 where α = 0.

The objective never increases (each block step is an exact block minimum), and in the validation below every pixel reached the global optimum found by multi-start L-BFGS-B. Zero iterations reproduce the old one-shot fit exactly.

Speed
  • Python (numpy float64, 1024², K = 3, 32 iterations): ≈ 4.7–6.3 s on this node under heavy shared CPU load (load average 83–125 on 96 cores); the one-shot fit takes ≈ 0.2–0.25 s. Used once per generated image in evaluation, not per preview.
  • Browser code (rgbaFromComposites, Node 24, one thread, 1024², K = 3): 0 iterations 250 ms, 32 iterations 388 ms; each pixel stops once a step moves α by less than 1e-7. It matches the Python fit to |Δα| ≤ 6e-8, |ΔF| ≤ 1.4e-6 on 4,096 noisy pixels with K = 3 gray levels and K = 9 RGB colors.

Glossary
Splitter
The FIBO2 variant (manifest §17) that paints the same object three times, on gray, white and black, so alpha can be computed.
α (alpha)
Opacity per pixel: 1 = solid object, 0 = fully clear.
F
The object's own color at a pixel, straight (not multiplied by α).
Color decontamination
Removing the background's color that bleeds into semi-transparent edge pixels, so F is the object's true color.
ILS
Iterative least squares: here, alternating exact least-squares solves for F (α fixed) and α (F fixed), each clipped to its box.
Box-constrained
Each unknown must stay in its own interval, here [0, 1].
L-BFGS-B
A quasi-Newton optimizer for smooth problems with box bounds; used here with 8 random starts as the reference optimum.
Projected Adam
Gradient descent with the Adam update, clipping α and F into [0, 1] after every step.
