H3 Magic, gray magic adapter: the training images and their captions

Dataset page of the gray magic adapter. Back to the journal.

The gray magic adapter is the third LoRA we train on the MiniMax H3 video model. It teaches H3 to paint a subject on a flat 50% gray background. It trains on top of H3 with the Pexels adapter and the image-gen adapter baked in.

stock H3→+ Pexels adapter (baked)→+ image-gen adapter (baked)→+ gray magic adapter (trained here)

The data is 10,000 MAGICK images (plus 20 held out), each composited on 0.5 gray and area-downsampled to 512×512, single frames. Gemini wrote new captions in the H3 prompt format, from the image alone, with no audio. The captions describe only the subject, never the background, because the gray background is what the adapter must learn.

48 random training images with their captions

Fixed sample: the first 48 captioned train images ordered by md5(page_id). Each PNG is the exact 512×512 file the adapter trains on, copied unchanged. Under each: the new H3 caption in full, then the old MAGICK caption it replaces. The new captions were written after we told Gemini to leave the background out. 11 of the shown captions contain the word gray or grey; check them: they should name the subject's own color (gray fur, a gray coat), not the backdrop.

Glossary
adapter
A small set of extra weights trained on top of a frozen model to change its behavior. Ours are LoRAs.
LoRA
Low-rank adaptation: the adapter stores the weight change of each layer as a product of two thin matrices, so it is small and cheap to train.
bake
Add an adapter's weight change into the base weights for good. The next adapter then trains on the changed model, so its own LoRA holds only what is new.
MAGICK
Our image set of single subjects with an alpha matte. Here each subject is composited on 50% gray (0.5 in each channel) and resized to 512×512.
H3 caption format
The long, visual-only prompt style that H3 was trained with: shot type, subject, appearance, setting and light, in plain prose after the prefix integrated_multimodal_description: [Shot 1]. No audio, no background talk for these images.
validation (val)
Images used only to measure validation loss. Never trained on.
